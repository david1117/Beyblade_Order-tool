========================================
 戰鬥陀螺上架監控 beyblade_moniter — 使用說明
========================================

【這是什麼】
一個跑在你自己電腦上的小工具，同時盯四家商店的戰鬥陀螺：
  Funbox（shop.funbox.com.tw）
  誠品線上（eslite.com）
  momo（momoshop.com.tw）
  墊腳石（tcsb.com.tw）
一偵測到有貨就通知＋自動放進購物車／跳結帳頁。
最後的「刷卡．送出訂單」永遠是你本人按，工具不碰付款。


【檔案清單】
  start_funbox.bat …… 啟動用（會自動安裝環境）雙擊這個就對了
  server.py …………… 主程式（偵測＋儀表板伺服器）
  monitor.py ………… Funbox 搜尋解析
  dashboard.html …… 儀表板畫面
  config/ …………… 你的設定（四家分開；含登入 cookie，勿外流）
  config.sample/ …… 乾淨的設定範本（沒有 cookie，可分享）
  eslite_grab.user.js  誠品腳本 v1.8（自動加入購物車＋step2 選取貨付款）
  momo_grab.user.js …… momo 腳本  v2.0（放入購物車＋多本合併開購物車）
  tcsb_grab.user.js …… 墊腳石腳本 v3.5（商品頁自動加入＋結帳選配送/門市/發票）
  funbox_grab.user.js … Funbox 腳本 v1.2（商品頁自動加入＋結帳選超商/付款/發票/已存卡片）
  funbox_cloud.gs …… 選用：Google Apps Script 雲端版（電腦關機也能偵測通知）
  使用說明.txt ……… 本檔

  ※ 四支腳本請確認版本相符，舊版會有已修掉的問題。


========================================
 一、安裝（第一次）
========================================

1) 安裝 Python（只要做一次）
   https://www.python.org/downloads/
   安裝時務必勾選「Add Python to PATH」。

2) 把整包解壓到同一個資料夾（例如 D:\Funbox_beyblade）。

3) 雙擊 start_funbox.bat
   它會自動檢查並安裝需要的套件：
     requests / beautifulsoup4 …… 抓網頁
     curl_cffi ………………………… 很重要！偽裝成真瀏覽器的連線指紋。
                                  沒裝的話誠品/momo 會回 429（擋機器人），
                                  導致所有商品都顯示缺貨。
   跑起來後瀏覽器會自動打開儀表板 http://localhost:8787/

4) 安裝四支瀏覽器腳本（Tampermonkey）
   先在你「平常購物的那個瀏覽器」安裝 Tampermonkey 擴充功能，
   並在擴充功能設定裡開啟「允許使用者指令碼 / Allow user scripts」。
   然後新增這四支（用記事本開啟、整段複製貼上）：
     eslite_grab.user.js … 誠品自動加入購物車 → step2 選好取貨付款
     momo_grab.user.js  … momo 準點搶購 / 自動搶
     tcsb_grab.user.js  … 墊腳石結帳自動選配送＋門市＋發票
     funbox_grab.user.js … Funbox 結帳自動選超商＋付款＋發票
   ※ 腳本一定要裝在「你有登入商店的那個瀏覽器」。

5) 保持登入（這是最重要的一步）
   funbox、誠品、momo、墊腳石 四個網站都在瀏覽器登入好，就這樣。
   ※ 不需要設定 cookie。四家都是靠「你瀏覽器的登入狀態」＋Tampermonkey 腳本
     幫你加入購物車。cookie 是進階選項（見第四節），新手可以完全略過。


========================================
 二、每天怎麼用
========================================

雙擊 start_funbox.bat → 視窗別關（關掉就停止監控）→ 儀表板會開啟。

儀表板上方四個分頁：Funbox / 誠品 / momo / 墊腳石
  右上「立刻偵測」：不等輪詢，馬上查一次。
  右上「偵測中（點此停用）」：整家商店的偵測開關。
  每張卡右上「自動:開/關」：這個品項要不要自動放購物車。
      → 四個分頁各自獨立：在墊腳石關掉某型號，不會影響 Funbox 的同名型號。
      → 已經買到的品項，就把它的「自動」關掉，避免又被放進購物車。
      → 「開」著的品項，每次偵測到有貨就會再放一次（不會自己記住買過了），
        所以「買到就關掉」是你控制數量的方式。
  「📋 動作紀錄」分頁：每次偵測到有貨、加入購物車、失敗都會留下時間戳，
      上方還有「今日偵測到幾次 / 成功加入幾件 / 失敗幾次」的統計。
      用途：確認到底有沒有成功搶到，不會錯過了卻不知道。
      紀錄會存進 events.jsonl，關掉程式重開也看得到。
  「前往購物車」：跟著分頁切換到對應商店的購物車。
      ※ momo 已改版，購物車沒有可直接連的固定網址，這顆會開 momo 首頁，
        登入後點右上角購物車即可。


========================================
 三、四家店的運作方式（不一樣）
========================================

● Funbox
  預設（免 cookie）：偵測到有貨 → 自動開商品頁 → funbox_grab 腳本用你的
  登入狀態按「加入購物車」→ 跳購物車頁 → 自動選好配送/付款/發票。
  進階（有填 cookie）：後端直接放購物車，最快、不用開瀏覽器；
  每個型號上限 1 件，多件也只開一次購物車頁。cookie 過期會自動退回腳本模式。

  結帳自動設定（選用）：裝 funbox_grab.user.js 後，開啟購物車頁就會自動
  按「立即結帳」進到配送步驟，並選好「超商 → 7-11 取貨 → 信用卡 → 手機載具」，
  門市沿用你帳號記住的（南京西門市）。
  ※ 信用卡卡號腳本一律不碰，卡號與最後「送出訂單」由你本人完成。
  ※ 要改超商/付款/發票，編輯腳本最上面的 WANT_SHIP / WANT_PAY / WANT_INVOICE。

● 誠品
  購物車在瀏覽器端，程式無法直接放，所以走「儀表板＋腳本」合作：
  偵測到有貨 → 自動開商品頁（網址帶暗號 ?mgauto=1）
             → eslite_grab 腳本自動點「加入購物車」
             → 確認頁首購物車數字真的增加 → 跳 /cart/step2 結帳頁
             → 在 step2 自動選好「台灣7-ELEVEN取貨 ＋ 7-ELEVEN超商取貨付款」
               （畫面最上方會出現綠色橫幅提示已設定完成）
  要不要自動加入，完全由儀表板那張卡的「自動:開/關」決定。
  你只需確認門市與商品無誤，自己按最後的「確認結帳」送出訂單。
  ※ 想改成別家超商：編輯 eslite_grab.user.js 最上面的 WANT_SHIP / WANT_PAY 關鍵字。

● momo
  momo 搜尋會撈到一堆溢價的第三方賣家，所以改成「鎖定官方商品編號 i_code」。
  設定方式：把 momo 商品網址給 Claude，他會抽出 i_code 幫你加進 config.json。
  後端會抓該商品頁的「正價 / 開賣時間 / 庫存」：
    有「M/D H:MM 開賣」橫幅 = 官方預售
        → 開賣前約 2 分鐘自動開商品頁並帶開賣時間
        → momo_grab 腳本對時後準點自動「直接購買」
    沒有開賣橫幅、有庫存 = 已開賣 → 立刻開頁自動搶
  腳本會自動把配送方式選成「超商/i郵箱/myfone 門市取貨」（不是快速到貨）。
  取貨門市與刷卡送出，由你本人完成。

● 墊腳石（www.tcsb.com.tw）
  用關鍵字偵測，跟 funbox／誠品一樣：tcsb.targets 一行一個關鍵字字串。
  背後走墊腳石官方搜尋 API（/api/products），讀 is_saleable 判斷有沒有貨，
  不需要瀏覽器腳本。墊腳石是綜合書店，關鍵字要夠精確。
  也可以精準鎖定單一商品：直接寫商品網址或條碼（例如 4711438507363）。

  自動加入購物車：
  預設（免 cookie）：偵測到有貨 → 自動開商品頁 → tcsb_grab 腳本用你的
  登入狀態按「加入購物車」→ 跳結帳頁 → 自動選好配送/門市/發票。
  進階（有填 cookie）：後端直接放購物車，最快、不用開瀏覽器，
  而且會先檢查購物車避免重複加。
  結帳頁預設就是「7-ELEVEN 取貨付款」，你只要確認金額後按「送出訂單」。

  cookie 取得：登入 www.tcsb.com.tw → F12 → Network → 重新整理
  → 點 Name 是 www.tcsb.com.tw 的那筆 → Request Headers 的 cookie: 整行複製。
  正確的 cookie 會包含 XSRF-TOKEN 與 _session；若看到 __Secure-3PSID 或 NID
  就是複製到 Google 的 cookie（錯誤，且那等同你的 Google 帳號憑證，別外流）。

  結帳自動設定（選用）：裝 tcsb_grab.user.js 後，一進結帳頁就會自動選好
  「全家取貨付款 ＋ 全家京鋒店」，只剩最後一顆「送出訂單」你自己按。
  要換超商或門市，改腳本最上面的 WANT_SHIP / WANT_STORE。
  注意：加入購物車不會保留庫存，庫存是送出訂單當下才扣，所以要盡快送出。

  驗證：打開 http://localhost:8787/api/tcsb_test
        cart_http 要是 200、product_id 要是數字，就代表設定成功。
        加 ?add=1 會實際測試放入購物車一次（不會結帳）。

  ※ 準點搶購最保險的做法：開賣前自己先把商品頁開好，
    在右下角面板填好日期時間、模式選「直接購買」、按「啟動」，
    看到綠色倒數（已對時）才算布署成功。


========================================
 四、設定檔（config 資料夾，四家分開）
========================================

設定已經依平台拆開，要改哪一家就開哪一個檔，不用在一大包 JSON 裡找：

  config/funbox.json … Funbox 的型號清單、cookie、幾秒查一次
  config/eslite.json … 誠品的關鍵字清單
  config/momo.json  … momo 的官方商品清單（i_code）
  config/tcsb.json  … 墊腳石的關鍵字清單、cookie
  config/common.json … 四家共用：連接埠、彈跳提示、Telegram 推播

每個檔裡都有「_說明」欄位寫明用途，看著改就好。
（首次啟動會自動從舊的 config.json 拆出這些檔，你原本的設定與 cookie 都會保留。
  舊的 config.json 會留著當備份，之後不再讀取。）

【常用欄位】
  targets ………… 要監控的清單，一行一個字串，最後一行不加逗號。
  enabled ………… 這家要不要偵測。
  auto_add / auto_grab … 偵測到有貨要不要自動放購物車。
  session_cookie … 【可留空，新手不用管】留空＝免 cookie 模式，靠瀏覽器登入＋腳本。
                   想要更快、不用開瀏覽器才填（取得方式見檔內 _cookie怎麼拿）。
  poll_interval_seconds … 這家幾秒查一次。

JSON 格式提醒：每個項目之間要有逗號，最後一個項目後面不要加逗號。
改完存檔後要重開 start_funbox.bat 才會生效。


========================================
 五、常見問題
========================================

Q：批次檔一閃就關掉？
   通常是 Python 沒安裝或沒加入 PATH。重裝 Python 並勾「Add Python to PATH」。

Q：誠品/momo 全部顯示缺貨，連明明有貨的也是？
   多半是 curl_cffi 沒裝成功（被回 429）。
   在資料夾按右鍵開命令列，執行：  py -3 -m pip install curl_cffi
   驗證：瀏覽器打開 http://localhost:8787/api/eslite_test
        最上面應顯示 curl_cffi(impersonate=chrome)，http_status 應為 200。

Q：Funbox 說已加入但購物車是空的？
   cookie 過期或複製到不完整的 cookie。重新複製含 _cyberbiz_session 的整行。

Q：Tampermonkey 面板沒出現？
   擴充功能設定要開「允許使用者指令碼」，並確認腳本沒被停用、網址符合。

Q：momo 按了「直接購買」跳「直接購買失敗」？
   常見原因：已售完、未登入（直接購買必須登入）、或該商品限購且你已下過單。
   把商品頁強制重新整理（網址後面加 &_r=1）看真實狀態。


Q：誠品同一件又被放進購物車一次？
   這是設計如此：只要那張卡的「自動」是開的，每次偵測到有貨就會放。
   買到之後請把該品項的「自動」關掉。

Q：怎麼知道有沒有真的搶到 / 是不是錯過了？
   看儀表板的「📋 動作紀錄」分頁。綠色＝成功加入購物車，紅色＝失敗（會寫原因），
   藍色＝偵測到有貨並開了商品頁。也可以直接開資料夾裡的 events.jsonl 看全部紀錄。

Q：換電腦 / 重新安裝怎麼保留設定？
   把 config 資料夾（你的目標清單＋cookie）、
   disabled.json（哪些品項關了自動）、stores.json（哪家店關了偵測）
   複製到新資料夾即可，其餘檔案用壓縮包內的新版。


========================================
 六、備份與分享
========================================

備份：整個資料夾複製一份即可，重點是 config 資料夾。

分享給別人：請用 beyblade_moniter_package.zip（內含 config.sample 範本，
沒有你的 cookie）。千萬不要直接把自己的 config 資料夾給別人。

移機：解壓 zip → 把 config.sample 改名成 config（或貼上你自己的 config 資料夾）
      → 雙擊 start_funbox.bat →
      在新電腦的瀏覽器裝好四支 Tampermonkey 腳本並登入四家商店。


========================================
 七、安全須知
========================================

* 這個工具只會「加入購物車 / 開啟結帳頁」，
  絕不會替你輸入信用卡、也不會替你送出訂單。最後一步一定是你自己按。
* config 資料夾內含你的登入 cookie，等同你的登入狀態，
  請勿把這些檔案或整包壓縮檔傳給別人、上傳雲端或貼到聊天室。
  要分享工具時請用 config.sample（已清空 cookie 的範本）。
