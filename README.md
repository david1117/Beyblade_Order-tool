# Funbox 上架監控

偵測指定型號一上架就立刻通知你，你再手動快速結帳。**這部分完全在你電腦上跑，不花任何 AI token。**

## 檔案

| 檔案 | 用途 |
|------|------|
| `config.json` | 你的設定（監控型號、檢查頻率、結帳資料）。**只存在你電腦，別外流。** |
| `monitor.py` | 監控腳本：定時查詢商店搜尋，偵測到型號就發出通知並自動開啟商品頁。 |
| `watchlist.log` | 執行紀錄（自動產生）。 |

## 安裝（只需一次）

```bash
pip install requests beautifulsoup4 plyer
```

## 使用

1. 打開 `config.json`，填好你要監控的型號（預設已放 UX-04 / UX-11 / UX-03 / UX-20）。
2. 執行：
   ```bash
   python monitor.py
   ```
3. 讓它一直開著。偵測到型號可購買時，會：嗶聲 + 桌面通知 + 自動開啟商品頁。
4. 停止：`Ctrl+C`。

## 檢查頻率

`config.json` 裡的 `check_interval_seconds`，預設 60（每分鐘一次）。**不要低於 30 秒**，以免被網站擋 IP。此輪詢不使用 AI token，成本為零。

## 關於自動下單

目前這套只做「偵測 + 通知」。真正的自動結帳（門市取貨 / 貨到付款）是下一步，需要：

1. 你先在瀏覽器登入商店（結帳沿用你的登入狀態）。
2. `config.json` 的 `checkout` 區填好取貨門市與收件資料。
3. `AUTO_SUBMIT` 預設 `false` = 幫你填到最後，**最後的「送出訂單」由你按**。設 `true` 才會無人自動送出真實貨到付款訂單（風險自負）。

結帳自動化會另外用瀏覽器實際走一次流程來對應真實欄位後再交給你。
