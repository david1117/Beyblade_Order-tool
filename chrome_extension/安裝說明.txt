========================================
 戰鬥陀螺上架監控（Chrome 外掛版）— 安裝說明
========================================

【這是什麼】
把原本「Python + 4 支 Tampermonkey 腳本」整合成一個 Chrome 外掛。
安裝一次就好，不用裝 Python、不用開黑色命令列視窗、不用複製 cookie。

⚠ 目前是測試版：墊腳石與誠品的偵測已驗證可用，
  momo 與 Funbox 的偵測寫好了但還沒實測。
  要搶「準點開賣的限量款」請還是用 Python 版（見下方「兩個版本怎麼選」）。


========================================
 一、安裝步驟（約 2 分鐘）
========================================

1) 打開 Chrome，網址列輸入：
      chrome://extensions
   按 Enter。

2) 右上角把「開發人員模式 / Developer mode」打開。

3) 左上角出現三顆按鈕，點「載入未封裝項目 / Load unpacked」。

4) 選擇這個資料夾：
      D:\Funbox_beyblade\chrome_extension
   （選資料夾本身，不要進去選裡面的檔案）

5) 清單出現「戰鬥陀螺上架監控」就成功了。
   建議點一下右上角的拼圖圖示 📌 把它固定在工具列，之後比較好按。


========================================
 二、第一次設定
========================================

1) 先在 Chrome 登入這四個網站（很重要，外掛靠這個登入狀態幫你加入購物車）：
      shop.funbox.com.tw
      www.eslite.com
      www.momoshop.com.tw
      www.tcsb.com.tw

2) 在 chrome://extensions 找到這個外掛 → 點「詳細資料」→ 點「擴充功能選項」
   （或在工具列的外掛圖示上按右鍵 → 選項）

3) 四個區塊分別填入要監控的東西，一行一個：

   🧸 Funbox    型號或商品名，例如：
                  UX-04
                  BX-35

   📚 誠品      關鍵字（要夠精確，誠品是綜合書店），例如：
                  鬼滅之刃 1
                  戰鬥陀螺收納箱

   🛍️ momo      商品編號，或直接貼商品網址，例如：
                  15468181
                  https://www.momoshop.com.tw/product/15341959

   🪜 墊腳石    關鍵字，或商品條碼／網址，例如：
                  戰鬥陀螺收納箱
                  9789863128915

4) 每區上方有兩個勾選框：
      「偵測這家」    → 要不要監控這家店
      「有貨自動加入購物車」 → 偵測到有貨要不要自動開商品頁加入

5) 按「儲存設定」。想馬上測試就按「立刻偵測一次」。


========================================
 三、平常怎麼用
========================================

裝好就會在背景自動跑，Chrome 開著就好。

  • 偵測到有貨 → 右下角跳 Chrome 通知
  • 若該店開了「自動加入購物車」→ 自動開商品頁，把商品加入購物車，
    再把結帳頁的配送方式、付款方式、發票都選好
  • 最後的「送出訂單」一律由你本人按（外掛不會替你下單、不碰信用卡）

  • 點工具列的外掛圖示 = 立刻偵測一次（不用等排程）


========================================
 四、兩個版本怎麼選
========================================

  情境                          建議用哪個
  ────────────────────────────  ──────────────
  平常掛著等補貨                 Chrome 外掛（省事，不用開命令列）
  搶「準點開賣」的限量款          Python 版（可以 10 秒查一次）
  想看完整的動作紀錄與統計        Python 版（有「動作紀錄」分頁）

原因：Chrome 對外掛的背景排程有限制，最快只能「1 分鐘」查一次；
Python 版沒有這個限制，funbox 可以設到 10 秒。
兩個版本可以同時存在，不會互相干擾。


========================================
 五、常見問題
========================================

Q：外掛裝好了，但沒有任何反應？
   1. 確認四個網站都在 Chrome 登入了
   2. 確認「選項」裡有填東西並按過「儲存設定」
   3. 點外掛圖示手動偵測一次看看
   4. 到 chrome://extensions 點「服務工作者 / service worker」，
      看主控台有沒有紅字錯誤

Q：都沒有跳通知？
   Windows「設定 → 系統 → 通知」裡要允許 Chrome 顯示通知。
   另外只有「從缺貨變成有貨」的那一刻才會通知，
   本來就有貨的商品不會一直重複吵你。

Q：偵測全部顯示沒貨，但我看網站明明有？
   通常是那家網站擋了機器人請求。點外掛圖示手動偵測一次；
   若持續如此，改用 Python 版（它有 curl_cffi 可以繞過這種封鎖）。

Q：更新外掛內容後沒生效？
   到 chrome://extensions，在這個外掛的卡片上按「重新載入 ⟳」。

Q：會不會自動幫我下單？
   不會。外掛只做「加入購物車 + 把結帳選項選好」，
   信用卡卡號不碰（那在金流商的獨立框架內，外掛讀不到），
   「送出訂單」永遠是你自己按。

Q：外掛會看我其他網站的資料嗎？
   不會。權限只申請那四家商店 + 全家門市地圖的網域，
   其他網站外掛完全讀不到。


========================================
 六、檔案結構（給想改的人）
========================================

  manifest.json    外掛設定：權限、要注入哪些網頁
  background.js    背景偵測：四家輪詢、判斷有沒有貨、發通知、開商品頁
  options.html/js  設定畫面
  content/
    funbox.js      進到 funbox 網頁時執行：加入購物車、結帳選項
    eslite.js      誠品
    momo.js        momo
    tcsb.js        墊腳石（含全家門市地圖自動選店）
  icon*.png        圖示

要改「預設選哪家超商 / 哪個門市 / 哪種發票」，
編輯 content/ 裡對應的檔案最上面那幾行設定即可，
跟 Python 版的 Tampermonkey 腳本是同一套寫法。
