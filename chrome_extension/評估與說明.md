# 改寫成 Chrome 外掛：評估與雛形

## 結論先講

**值得做，而且很適合。** 對「新手友善」這個目標來說，Chrome 外掛比現在的架構好很多：

| | 現在（Python + Tampermonkey） | Chrome 外掛 |
|---|---|---|
| 要裝的東西 | Python、4 支腳本、Tampermonkey、批次檔 | **1 個外掛** |
| 設定方式 | 改 JSON 檔 | 圖形介面填表 |
| 要開著什麼 | 黑色命令列視窗 + 瀏覽器 | 只要 Chrome |
| cookie | 進階選項要手動複製 | **完全不用**（外掛本來就帶你的登入狀態） |
| 誠品權杖問題 | 無法用 cookie（需 Bearer） | **可以**（外掛不受跨網域限制） |

最大的技術優勢：外掛有 `host_permissions`，**發請求時會自動帶上你的登入狀態，而且沒有跨網域限制**。
這正好解掉兩個現有痛點——不用再複製 cookie，誠品那個 `Authorization` 權杖問題也自然消失。

## 移植難度

實測過現有 4 支腳本，對 Tampermonkey 專屬 API 的依賴極少：

- `funbox_grab.user.js`（215 行）：0 處 → 直接改成 content script 即可
- `eslite_grab.user.js`（338 行）：只有宣告，實際 0 處
- `momo_grab.user.js`（383 行）：只有宣告，實際 0 處
- `tcsb_grab.user.js`（381 行）：2 處（`unsafeWindow.jQuery`、`unsafeWindow.openLightBox`），且都寫了備援路徑

所以四支腳本幾乎可以原封不動搬過來，把 `==UserScript==` 標頭換成 manifest 的 `content_scripts` 設定就好。

## 需要注意的限制（誠實說）

**1. 背景輪詢的時間限制**
MV3 的 service worker 大約閒置 30 秒就會被 Chrome 收掉，得改用 `chrome.alarms`，而 alarms 的最小週期是 **1 分鐘**。
現在 funbox 是 10 秒查一次，改成外掛後最快只能到 1 分鐘。
→ 解法：搶限量款時用「開著商品頁 + content script 自己重整」的方式補足，或保留 Python 版專門跑高頻。

**2. 沒有 DOM 解析器**
service worker 裡沒有 `DOMParser`，抓 funbox／momo 的 HTML 要改用正則比對（現有 Python 版本已經是這樣做，可直接翻譯）。

**3. 安裝方式**
沒上架 Chrome 線上商店的話，要用「開發人員模式 → 載入未封裝項目」。
自己用沒問題，要給別人裝就得上架（需開發者帳號、審查）。

**4. 通知**
`chrome.notifications` 比現在的 Windows 彈窗更穩定，但**電腦鎖定時不會有聲音提示**；
要手機推播還是得保留 Telegram 那條路。

## 建議做法

分兩階段，風險最低：

**階段一（這個資料夾）**：外掛負責「偵測 + 通知 + 自動加入購物車 + 結帳自動填」，
輪詢週期 1 分鐘。日常監控用這個就夠，安裝從「5 個步驟」變成「1 個步驟」。

**階段二（保留現有 Python 版）**：遇到「準點開賣搶限量」這種要秒級反應的場合，
才開 Python 版來跑高頻偵測。兩者可以並存，不衝突。

## 這個資料夾裡有什麼

```
chrome_extension/
  manifest.json      外掛設定（MV3）
  background.js      背景偵測：四家輪詢、通知、開商品頁
  options.html/js    設定畫面（取代 config 資料夾與儀表板）
  content/
    funbox.js        \
    eslite.js         |  由現有 4 支 Tampermonkey 腳本移植
    momo.js           |  （加入購物車、結帳自動選配送/付款/發票）
    tcsb.js          /
```

目前雛形已能運作的部分：**墊腳石與誠品的偵測**（都是 JSON API，最單純）、
設定畫面、通知、偵測到有貨自動開商品頁。
momo 與 funbox 的偵測需要解析 HTML，已預留位置但尚未完成。

## 安裝方式（測試用）

1. Chrome 網址列輸入 `chrome://extensions`
2. 右上角開啟「開發人員模式」
3. 點「載入未封裝項目」，選這個 `chrome_extension` 資料夾
4. 點外掛圖示 → 設定 → 填入要監控的商品

## 安全性

跟現在的版本一樣：只做「加入購物車 / 開啟結帳頁 / 自動選配送付款」，
**不碰信用卡卡號，也不會替你送出訂單**，最後一步一定是你本人按。
外掛的權限只申請這四家商店的網域，不會讀取其他網站。
